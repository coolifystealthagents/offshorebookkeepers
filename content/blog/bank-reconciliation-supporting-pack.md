## Practical guidance

Start with the source record, date, owner, and amount relevant to bank reconciliation supporting pack. Record each item separately so timing and classification differences remain visible.

## Keep the evidence connected

 Include the statement, book balance, outstanding items, fees, transfers, and adjustment references. The packet should allow a reviewer to retest the ending balance without rebuilding it.

## Review the exception list

 Use the same packet structure each period so cleared items, new items, and aged reconciling items are easy to distinguish.
