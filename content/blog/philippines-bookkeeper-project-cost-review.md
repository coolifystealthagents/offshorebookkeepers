## Establish the project key
## Trace a cost before reclassifying it
When a $1,400 vendor bill has no project code, compare its description, purchase request, contract, and delivery period. Record the candidate project or mark it unresolved; do not infer from the vendor’s name. The Philippines bookkeeper can prepare the coding question and update an approved answer, while the project owner decides whether the cost belongs to the job.

## Compare cost to the project story
Review vendor bills, time records, payroll allocations, purchases, and invoices using the same project identifier. Explain a spike by a documented scope change, timing, missing allocation, or error. A useful review keeps original coding visible and distinguishes a true project overrun from a late posting or a cost waiting for owner confirmation.
Use a stable project or job identifier in vendor bills, time records, payroll allocations, purchase records, and invoices. A Philippines bookkeeper can then trace a cost without inferring the project from a vendor name.

## Match source records
Review direct costs, subcontractors, materials, labor, reimbursable expenses, and committed purchase orders against the project ledger. Flag costs with a missing ID, unexpected category, or late posting.

## Separate facts from margin choices
The bookkeeper can show actual cost, billed amount, unbilled work, and missing support. The project owner decides whether scope changed, a cost is recoverable, or a client conversation is needed.

## Keep time and payroll distinct
Time records, payroll, and contractor invoices may use different periods. Document the allocation basis and cutoff so a project summary does not imply precision that the source data cannot support.

## Review by exception
Prioritize new vendors, large variances, negative margins, unapproved spend, and costs posted after close. Give each item an owner and a requested action rather than sending a raw export.

## Hand off the project view
Deliver cost by category, source completeness, billing status, open questions, and reviewer notes. The result is useful for a manager while keeping commercial decisions with the project owner.
