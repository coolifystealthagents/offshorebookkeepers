## Write the exception path first

For Offshore Bookkeepers's virtual assistant operations team: If a risk is outside the team's authority, escalate it with the impact and the decision needed; do not keep it on a local list. Every exception needs a reason code, a next owner, a recheck date, and the action the specialist must not take. Test the rule on one ordinary item, one exception, and one unresolved case before expanding it.

In Offshore Bookkeepers's virtual assistant operations workflow: Use a small code set: missing source, conflicting source, wrong period, identity mismatch, stale approval, system failure. Keep the source and destination evidence attached so a later reviewer can verify the close.
