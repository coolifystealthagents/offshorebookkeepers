## Practical guidance

Start with the source record, date, owner, and amount relevant to project cost-code review. Record each item separately so timing and classification differences remain visible.

## Keep the evidence connected

 Compare bills, time records, purchase records, and project codes. A proposed reallocation should include the reason and be approved by the project or finance owner.

## Review the exception list

 Confirm corrected coding appears in both project reporting and the general ledger before closing the exception.
